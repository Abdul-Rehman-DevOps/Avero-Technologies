# Avero design rewrite — research synthesis

Patterns studied across leading tech / enterprise sites (Stripe, Linear, Vercel, Notion,
Apple, Microsoft, Salesforce, IBM, Accenture, Cloudflare, Shopify, and peers).
No logos, copy, colors, or assets were copied.

| Pattern borrowed | Applied as |
| --- | --- |
| Full-bleed cinematic hero | Photography hero with brand-first wordmark |
| One CTA family in viewport | Start a project + See case studies |
| Dual-path mega menu | Services / Industries / Case Studies panels |
| Product-led proof bands | Case studies + service tiles with real content |
| Theme tokens | Light / Dark / Blueprint CSS variables |
| Editorial photography | Unsplash tech / workspace imagery throughout |

## Visual identity

- Display: Space Grotesk
- Body: Source Sans 3
- Signal: cyan teal on cool mist (not purple SaaS cliché)
- Motion: ken-burns hero, scroll reveal, hover scale on media
