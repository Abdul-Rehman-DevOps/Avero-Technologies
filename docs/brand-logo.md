# Avero brand mark — Signal Apex

## Concept

**Signal Apex** — a geometric “A” cut by a teal production-signal beam, with an apex node for focus and precision.

| Element | Meaning |
| --- | --- |
| Navy pillars | Structure, engineering, permanence |
| Teal crossbar | Production signal / observability / live systems |
| Apex node | Precision, the point of delivery |

Palette: `#07111F` (ink), `#0D8F9C` (signal), `#FFFFFF`, `#7A8BA6` (muted).
