Cost surprises rarely come from a single expensive instance. They come from architecture that never had a cost model.

## Design for environments

Every long-lived staging and developer sandbox needs an owner, a budget, and a shutdown policy.

## Watch data movement

Egress and duplicated pipelines quietly dominate invoices. Map data flows early.

## Prefer paved paths

Golden-path templates with right-sized defaults beat ad-hoc resource sprawl.
